Reliable WooCommerce order synchronization with external ERP systems using signed webhooks, retries, and an audit log.

== Description ==

OrderBridge is a portfolio reference implementation for background order export, duplicate-safe API delivery, signed inbound status webhooks, and synchronization auditing.

This release requires project-specific mapping and live integration testing before production deployment.

== Installation ==

1. Upload and activate the plugin.
2. Open WooCommerce > OrderBridge.
3. Configure the ERP API URL, API key, and shared webhook secret.
4. Test the connection.
